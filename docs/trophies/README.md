# Трофеи и интерактивные прохождения

Маршруты: `/trophies` и `/trophies/gothic-remake`. Разработка находится в ветке `codex/trophy-tracker`. Production deploy и миграция рабочей Supabase не выполнялись.

## Что реализовано

Главная страница игры — интерактивный гайд. Он пересчитывает следующий доступный шаг после подтверждения действия, учитывает зависимости и текущие условия персонажа, показывает полезные действия в выбранной локации, причины блокировок, пропускаемые действия и альтернативы. Полный маршрут доступен отдельно. Спойлеры будущих глав скрыты по умолчанию; их просмотр не делает будущий шаг рекомендуемым сейчас.

Выполнить действие можно в произвольном порядке, отложить или отменить. Подтверждение уже выполненного действия разрешено даже при неполном журнале: приложение не запрещает пользователю исправить свои записи. Зависимые задания не отмечаются автоматически. Перед повышением главы открывается контрольный список обязательных действий, уроков, пропускаемых предметов и незавершённых цепочек с напоминанием об отдельном сохранении PS5.

Отдельно хранятся:

- Вручную подтверждённые трофеи PSN.
- Общая история изучения уроков и получения карт.
- Накопительный журнал боевых и ремесленных действий.
- Каждое прохождение и его ветки сохранений персонажа.
- Отметки, требующие проверки, заметки и собственные пункты.

Создание ветки копирует текущее состояние персонажа, но не дублирует глобальные счётчики. Возврат к основному сохранению не отменяет трофей, полученный в другой ветке. Приложение не управляет файлами сохранений на PS5: сохраняться и загружаться в игре нужно самостоятельно.

Исходный персональный прогресс применяется отдельной кнопкой. Это глава 1, «Новичок», план Старого лагеря/мага Огня, сохранённое условие без сна, семь подтверждённых пользователем уроков (7/46) и одна названная карта из трёх покупок. К прежним пяти урокам по уточнению пользователя добавлены «Одноручное оружие — обучен» (указан как стартовый на «Новичке») и «Скалолазание». Две карты Грэма не угадываются. Уточнённый набор применяется только кнопкой первоначального импорта; существующий прогресс автоматически не меняется. Трофей Болотного лагеря записывается глобально, вступление текущего персонажа не предполагается. Второе прохождение создаётся как ещё не начатый план перманентной смерти.

## Каталог и источники

Основной каталог содержит 140 записей: 41 трофей PS5 (1 платина, 2 золота, 20 серебряных, 18 бронзовых), 46 уникальных уроков, 12 отдельных вариантов карт, 11 книг, 11 счётчиков, 16 заданий и 3 испытания. Подробности и источники находятся в каждой карточке и в JSON каталоге. Русские названия трофеев — редакционные переводы; оригинальные английские названия сохранены для поиска.

Количество вариантов карт в справочнике не объявляется подтверждённым порогом трофея: актуальное число для PS5 осталось спорным. Патч 1.0.4 исправляет Map Sniffer, но не публикует числовой порог. Сообщения о перепутанных трофеях прохождения без сна и перманентной смерти также помечены как требующие проверки.

Статус источника отделён от статуса действия пользователя. Непроверенные зависимости не создают категоричные запреты и не используются для уверенной рекомендации. Рекомендованная глава из руководства не превращается автоматически в обязательное игровое условие. Реестр не обещает, что каждое действие засчитывается игрой после загрузки старого сохранения.

Использованы собственные краткие пересказы фактов и прямые ссылки, а не скопированные полные руководства, чужие изображения или массивы игровой выгрузки. Обложка — собственная SVG-иллюстрация. У источников с требованиями атрибуции сохранены автор и прямая индексируемая ссылка сопоставимого размера. Исследовательские загрузки сайтов в Git не включаются.

## Архитектура

`src/lib/trophies/types.ts` определяет общий каталог; `catalog.ts` — реестр игр. `guides.ts` связывает игры с отдельными маршрутными данными. Чтобы добавить игру, нужно заполнить каталог и граф её действий, зарегистрировать их и проверить валидатором; алгоритм маршрутов не меняется. В интерфейсе нет пустых карточек будущих игр.

`routes.ts` — чистый движок без React и Supabase. Условия используют декларативные правила; зависимости допускают альтернативные наборы. Отдельно проверяются циклы, отсутствующие ссылки, противоречия и ограничения глав. Приоритет имеют подтверждённые риски пропуска, затем обязательные действия и подходящие действия рядом; роль и сложность могут уточнять порядок.

`saves.ts` проецирует отдельную ветку сохранения через пространство имён событий. Исходный журнал не переписывается. Экспортируется полный исходный журнал, а не проекция выбранной ветки. Формат и протокол хранения описаны в [STORAGE.md](./STORAGE.md).

Прогресс хранится в IndexedDB сразу после изменения. После Google-входа существующий Supabase-клиент синхронизирует только данные текущего пользователя. Гостевые записи не отправляются в аккаунт без явного переноса. Одновременные изменения одного поля не затирают друг друга: оба варианта показываются для разрешения. Счётчики объединяют приращения. Автосохранение текста дополнительно защищено восстанавливаемым локальным черновиком.

JSON экспорт/импорт включает все игры, прохождения, ветки и историю. Импорт объединяет ID, проверяет формат и целостность, не заменяет журнал. Перед массовыми изменениями создаются локальные резервные копии; восстановление добавляет обратные события. Полная история сохраняется.

## PWA

Манифест расположен в `/trophies/manifest.webmanifest`. Сборка создаёт `/trophies-sw.js`, зарегистрированный только со scope `/trophies`. Он не контролирует другие приложения. В кеш входят проверенные статические файлы текущего экспорта; запросы Google, Supabase и приватные ответы не кешируются. Обновление применяется явно и ждёт сохранения черновиков. Старые файлы открытых вкладок и кеш Gothic Locks сохраняются.
