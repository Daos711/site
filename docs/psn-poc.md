# PSN Trophy API PoC

Этот изолированный серверный proof of concept проверяет read-only получение trophy profile, полного списка игр и подробных trophy-данных одной выбранной игры через неофициальный PSN API. Он не создаёт UI, не пишет в базу данных и не изменяет данные PSN.

## Безопасность NPSSO

`PSN_NPSSO` фактически даёт доступ к PSN-аккаунту. Обращайтесь с ним как с паролем: не передавайте в чатах, аргументах командной строки, файлах репозитория или логах. NPSSO ориентировочно приходится вручную обновлять примерно раз в два месяца, но гарантированного срока действия нет.

Локально задайте секрет только через переменную окружения текущего процесса. Например, в PowerShell можно сначала установить `$env:PSN_NPSSO` в своей защищённой локальной сессии, а затем выполнить команду ниже. Не сохраняйте реальное значение в `.env.example` или другой tracked-файл.

Для ручного GitHub Actions запуска создайте repository secret `PSN_NPSSO`: **Settings → Secrets and variables → Actions → New repository secret**. Workflow `.github/workflows/psn-poc.yml` запускается только вручную через **Actions → PSN Trophy PoC → Run workflow**.

## Запуск

Unit tests не используют сеть и не требуют секрета:

```powershell
npm run psn:poc:test
```

Live-запуск с `PSN_NPSSO`, уже заданным в environment:

```powershell
npm run psn:poc
```

По умолчанию для подробной проверки выбирается наиболее недавно обновлённая незавершённая игра, либо наиболее недавно обновлённая игра, если все завершены. Конкретный trophy set можно указать дополнительной environment variable:

```powershell
$env:PSN_POC_NP_COMMUNICATION_ID = "<npCommunicationId>"
npm run psn:poc
```

Нормализованный отчёт появляется только локально в `.tmp/psn-poc/report.json`; путь игнорируется Git. Отчёт может содержать приватные данные игрового профиля, поэтому его нельзя коммитить, прикладывать к публичному workflow или публиковать.

Используемый PSN API неофициальный. Его endpoints и response schema могут измениться без предупреждения, поэтому адаптер вызовов отделён от нормализации отчёта.
