# Проверка Gothic Remake — Замки

Дата: 16 октября 2026 года. Проверена локальная интеграция в `site`; публикация не выполнялась.

## Автоматические проверки

- `npm run build`: статический экспорт всех 33 страниц сайта, включая `/apps/gothic-locks`, и проверка TypeScript.
- `npm run test:gothic`: 37 тестов ядра, 20 записей каталога и PWA. Все пройдены.
- `npm run test:elka-frame`: 8 существующих тестов сайта. Все пройдены.
- `node scripts/test-gothic-browser.cjs`: 12 приёмочных сценариев в Chromium. Все пройдены; необработанных ошибок JavaScript нет.
- `git diff --check`: ошибок пробелов нет.

В ядре независимо проверяются направленность связей, атомарный отказ при крайнем положении зависимой пластины, валидация некорректных данных, кратчайший путь, минимум переключений пластин, отличие лимита поиска от доказанной неразрешимости и каждое промежуточное движение. Тестовые модели не выдаются за реальные сундуки.

Для всех 20 импортированных конфигураций выполняется независимое воспроизведение до положения 4 у каждой пластины. Контрольные длины: Скатти — 31 единичное движение; Кор Галом с рецептом — 15; второй вариант Кор Галома — 59. При группировке количество команд меньше числа движений.

## Браузерная приёмка

1. Загрузка приложения и полный офлайн-кеш.
2. Старый лагерь → Скатти → Без навыка; нумерация снизу вверх.
3. Сохранение навыка и шага после перезагрузки, смена навыка без потери шага.
4. Инвалидизация устаревшей инструкции после изменения механизма, включая перезагрузку.
5. Копирование всей комбинации.
6. Перезагрузка, поиск и новый расчёт для Кор Галома с отключённой сетью.
7. Чтение полных лицензионных уведомлений без сети.
8. Ручной ввод, физическое направление, объединённая команда и завершение без сети.
9. Неразрешимая конфигурация: нет небезопасной подсказки.
10. Ширины 320, 360, 412, 768, 1440 CSS px, пустой поиск, фильтры вскрытых и ценных.
11. Семипластинчатый редактор на 320 px: горизонтальная прокрутка ограничена таблицей, страница не переполняется.
12. Восстановление после повреждённого JSON в localStorage.

Визуально просмотрены снимки настольного каталога и мобильного экрана Скатти. Текущая команда расположена выше схемы, подробная атрибуция раскрывается отдельно. Исходное состояние и связи доступны для сверки. Пользовательская отметка «Вскрыт» не является подтверждением результата игры.

Тест PWA отдельно проверяет полноту precache, отказ активации при недоступном файле, неприкосновенность чужих кешей, ожидание закрытия старых вкладок при обновлении, частичную потерю кеша и доступ к Worker/лицензиям без сети.

## Ограничения проверки

Игровой запуск на PS5 и установка на физический OnePlus 15 не выполнялись. Нет доказательства применимости исходных записей ко всем патчам игры. Не подтверждено совпадение всех переводов с официальной русской локализацией. Эти ограничения отображены в интерфейсе и аудите.

Локальная проверка использовала установленный Chromium 143 с bundled Playwright 1.62.1. У этой пары `navigator.onLine` после перезагрузки сбрасывается в `true`, даже когда сеть эмулируется как недоступная; это воспроизведено и на независимой `data:`-странице. Поэтому тест проверяет надпись «Без интернета» до reload, а после него подтверждает реальное отсутствие доступа новым некешированным запросом, загрузкой приложения из Service Worker и новым вычислением. В коде приложения обхода этой особенности тестовой среды нет.

Для самостоятельного повторения браузерной проверки см. `README.md`. Скрипт сохраняет снимки и JSON-отчёт в каталог `GOTHIC_TEST_OUTPUT`.
