## Пределы проверки

Проверка в запущенной игре и на PS5 не выполнена. Неизвестная версия игры не подменяется версией сборки сайта. Для восстановленных механизмов математическая гарантия относится к явно описанным предположениям и наблюдениям, а не подтверждает имя игрового экземпляра.

В данном Chromium/Playwright navigator.onLine после offline reload ненадёжен: отсутствие сети дополнительно подтверждается провалом запроса некешированного адреса, а сохранённые маршруты и ручной Worker-расчёт работают.

## Ограничения

Нет проверки в запущенной игре/на PS5. Ни один исходник не подтверждает одновременно игровую версию и профиль навыка для опубликованных наблюдений. Числа решённых синтетических тестов не считаются реальными сундуками.

Playwright1.62.1 использует установленный Chromium143. У этой пары navigator.onLine после reload возвращается в true даже при эмулируемом отключении сети (воспроизведено на независимой странице). Поэтому надпись «Без интернета» проверяется до reload, а после — фактическая неудача сетевого fetch и успешный локальный расчёт. В приложение обход не добавлен.

Сценарии и снимки создаёт scripts/test-gothic-browser.cjs. Публикация проверяется повторным запуском на HTTPS после GitHub Actions.
