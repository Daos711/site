# Проверка расширенного справочника

16 октября 2026. Локальный production build прошёл, 33 страницы экспортированы. npm run test:gothic: **55/55**; npm run test:elka-frame: **8/8**. Браузерная проверка: **15/15 групп**, ошибок JavaScript: 0.

## Что проверено

- Все 146 ID базы совпадают со строками интерфейса; каждый фильтр района, типа, местности и полноты возвращает ожидаемые ID.
- 24 конфигурации Arminek решены и независимо воспроизведены с проверкой каждой промежуточной позиции. Контроль: Скатти31, Кор Галом15/59; добавленные пещера41, мост25, кладбище29, лесорубы30 движений.
- Все десять замков Фиска проверены в интерфейсе для трёх навыков: нет исходных разрешённых матриц, поэтому нет выдуманных подсказок.
- Скатти и оба наблюдения Кор Галома решаются только после явной сверки состояния. Это математическое воспроизведение одной наблюдаемой матрицы при выбранной метке навыка, не подтверждение трёх игровых профилей.
- Независимые синтетические графы проверяют все три навыка, авторский порядок отключения, отсутствие транзитивного/обратного эффекта, границы, невозможные состояния и лимит поиска.
- Смена навыка сбрасывает прогресс/подтверждение, но сохраняет ручную матрицу. Повторное отключение связей невозможно даже после редактирования порядка. Изменённый механизм требует нового ввода и расчёта.
- Симулятор отклоняет целиком ход с выходом зависимой пластины за границу и пересчитывает маршрут от фактического состояния.
- Мобильные размеры 320/360/412/768/1440, семипластинная таблица, поиск, вскрытые/ценные, копирование, повреждённое хранилище.
- Реальный offline reload через Service Worker, новый Worker-расчёт и полные лицензии без сети. Отдельный некешированный fetch подтверждает отсутствие сети.
- Карта загружается только по нажатию через официальный разрешённый iframe. В тесте внешний iframe перехвачен для детерминированности; отдельно HTTP200 и отсутствие запрета встраивания проверены у живого URL.
- Короткий /apps/g/ сохраняет query/hash при переходе к основному адресу. Основной PWA scope сохранён; alias сам не обещает офлайн-режим.

## Ограничения

Нет проверки в запущенной игре/на PS5. Ни один исходник не подтверждает одновременно игровую версию и профиль навыка для опубликованных наблюдений. Числа решённых синтетических тестов не считаются реальными сундуками.

Playwright1.62.1 использует установленный Chromium143. У этой пары navigator.onLine после reload возвращается в true даже при эмулируемом отключении сети (воспроизведено на независимой странице). Поэтому надпись «Без интернета» проверяется до reload, а после — фактическая неудача сетевого fetch и успешный локальный расчёт. В приложение обход не добавлен.

Сценарии и снимки создаёт scripts/test-gothic-browser.cjs. Публикация проверяется повторным запуском на HTTPS после GitHub Actions.
