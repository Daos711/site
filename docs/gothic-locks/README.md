## Проверка и сборка

- npm run build — static export, Worker, лицензии, precache и короткий адрес.
- npm run test:gothic — 78 проверок решателя, каталога, профилей, прогресса и PWA.
- python scripts/test-gothic-column-cover.py — независимое доказательство покрытия на синтетических примерах.
- node scripts/test-gothic-expansion-browser.cjs — хижина, источники, ключи и новые фильтры на телефоне.
- node scripts/test-gothic-ready-browser.cjs — текущая браузерная приёмка всей базы и трёх навыков.
- node scripts/test-gothic-update.cjs — миграция старого офлайн-каталога на текущий без потери отметок.
- scripts/test-gothic-browser.cjs сохранён как исторический сценарий прежних карточек без готовых профилей; не является приёмкой текущего выпуска.

Для браузерных сценариев задайте PLAYWRIGHT_MODULE и CHROMIUM_PATH при внешних зависимостях; GOTHIC_TEST_URL / GOTHIC_TEST_OUTPUT управляют адресом и снимками. Для update-теста каталог результатов задаёт GOTHIC_UPDATE_OUTPUT.

## Данные

Готовые шаги, ссылки и каталог разделены. В данных сохраняются точный навык, источники, лицензия, известная версия игры и вид проверки. Неоднозначные модели хранятся явно; маршрут должен работать на каждой. Отсутствующая комбинация другого навыка не подменяется имеющейся. После смены навыка или модели старый шаг требует сверки состояния.

## Карта и публикация

Разрешённый iframe TH.GL загружается по нажатию. 386 обычных и 16 подводных маркеров карты не равны числу подтверждённых замков; чужой массив не копируется. Карте нужен интернет. Каталог, готовые шаги и решатель доступны офлайн после полной установки.

GitHub Actions deploy.yml публикует static export при push в main. Локальная сборка сама по себе не публикует сайт. Пользователь разрешил деплой существующего приложения.
