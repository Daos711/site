# Gothic Remake — Замки

Продолжение существующего приложения, 16 октября 2026. Основной маршрут /apps/gothic-locks/; /apps/g/ перенаправляет на него, сохраняя query и ссылку на карточку. Интерфейс и локальные отметки сохранены. Старые навыки не подтверждают матрицу автоматически; смена навыка сбрасывает инструкцию.

146 карточек, 24 конфигурации ручных наблюдений, 0 подтверждённых версией и навыком игровых решений. 44 карточки только с установленным местоположением, 102 неполные/спорные. Полный независимый аудит и правила подсчёта — [FULL-AUDIT.md](./FULL-AUDIT.md).

## Проверка и сборка

- npm run build — Next static export, Worker, иконки, лицензии, precache и короткий адрес.
- npm run test:gothic — решатель, 24 наблюдения, фильтры всей базы, навыки и PWA.
- npm run test:elka-frame — существующие регрессионные тесты сайта.
- node scripts/test-gothic-browser.cjs — браузерная проверка. Настройте PLAYWRIGHT_MODULE, CHROMIUM_PATH, GOTHIC_TEST_URL и GOTHIC_TEST_OUTPUT, если зависимости не установлены в проекте.

## Данные и навыки

Матрицы Arminek опубликованы как наблюдения игрока под заявленной автором MIT; отдельного LICENSE у источника нет, это отражено в notices. G1LockPickHelper исключает игровые массивы из MIT, поэтому они не включены. Dsazz получил данные из стороннего API — MIT кода не используется как разрешение на эту базу. Публичные руководства использованы только для самостоятельно изложенных фактов и ссылок.

Источник не указал навык для 24 наблюдений. Карточка сначала показывает позиции и направленные связи: расчёт открывается после явной сверки. При несовпадении введите реальное состояние. Ручной редактор хранит действующий граф выбранного уровня; для подтверждённого полного графа можно отдельно задать авторский порядок связей и однократно применить отключение 0/1/2 связей. Порядок строк матрицы не заменяет авторский порядок.

## Карта и офлайн

Официальный iframe TH.GL подключается по нажатию, с видимой ссылкой на автора согласно https://www.th.gl/developers. Он даёт доступ к 386 обычным и 16 подводным маркерам; это не 402 проверенных замка. Массив и изображения карты не скачиваются в приложение. Карте нужен интернет. Существующий каталог, решатель и лицензии доступны после отметки «Доступно офлайн». Короткий адрес является сетевым переходом; установленное PWA использует основной адрес.

## Публикация

GitHub Actions deploy.yml публикует static export при push в main. Разрешение владельца на деплой получено в этой задаче. Старое приложение было опубликовано в 557085b; этот выпуск продолжает его. Локальная сборка сама по себе ничего не публикует.
